# GFast V3.2 MySQL → PostgreSQL 迁移设计

## 背景

GFast V3.2 当前仅支持 MySQL，需完全替换为 PostgreSQL 14+。GoFrame gdb 已提供数据库抽象层，业务代码不依赖 MySQL 专有语法，迁移风险可控。

## 决策记录

| 项目 | 决策 |
|------|------|
| 迁移范围 | 完全替换 MySQL，删除 MySQL 驱动 |
| 数据迁移 | 全新部署，仅翻译 schema + 种子数据 |
| 标识符引号 | 去引号，依赖 PG 自动小写 |
| PG 版本 | 14+ |
| 类型映射 | 精确语义映射 |
| 主键自增 | `GENERATED BY DEFAULT AS IDENTITY` + 种子数据后 `setval` 同步 |
| 配置模板 | 极简替换，删 charset |
| 库名 | `token_flux` |
| casbin_rule | 新增自增 id 主键 |
| dbInit API charset 字段 | 去 required 校验 |
| SQL 文件 | 覆盖原 `gfast-v32.sql` |
| README | 同步更新为 PG 说明 |

### 5. `resource/data/gfast-v32.sql` — 全量重写（主要工作量）

14 张表的 MySQL DDL → PG DDL 翻译。

**类型映射规则：**

| MySQL | PostgreSQL | 应用场景 |
|-------|------------|----------|
| `tinyint(N) UNSIGNED` | `smallint` | 状态、标志位 |
| `int(N) UNSIGNED` | `integer` | 一般整型 |
| `int(N) UNSIGNED AUTO_INCREMENT` 主键 | `integer GENERATED BY DEFAULT AS IDENTITY` | 自增主键 |
| `bigint(N) UNSIGNED AUTO_INCREMENT` 主键 | `bigint GENERATED BY DEFAULT AS IDENTITY` | 大整型自增 |
| `bigint(N) UNSIGNED` | `bigint` | 大整型 |
| `varchar(N) CHARACTER SET ... COLLATE ...` | `varchar(N)` | 字符串 |
| `datetime` | `timestamp` | 时间 |
| 反引号 | 去掉 | 标识符 |
| `ENGINE=InnoDB ... ROW_FORMAT=COMPACT` | 删除 | 表选项 |
| `COMMENT '...'`（列/表级） | `COMMENT ON TABLE/COLUMN ... IS '...'` | 注释 |

**索引语法转换：**

- `PRIMARY KEY ... USING BTREE` → `PRIMARY KEY`
- `UNIQUE INDEX name(col) USING BTREE` → `CREATE UNIQUE INDEX name ON table(col)`
- `INDEX name(col) USING BTREE` → `CREATE INDEX name ON table(col)`

**种子数据序列同步：**

每张带显式 id 种子数据的表，在 INSERT 完成后追加：

```sql
SELECT setval(
  pg_get_serial_sequence('表名', '主键列名'),
  COALESCE((SELECT MAX(主键列名) FROM 表名), 1)
);
```

**casbin_rule 表变更：**

```sql
CREATE TABLE casbin_rule (
  id    bigint GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
  ptype varchar(10),
  v0    varchar(256),
  v1    varchar(256),
  v2    varchar(256),
  v3    varchar(256),
  v4    varchar(256),
  v5    varchar(256)
);
```

新增 `id` 主键列；种子 INSERT 不带 id 列（IDENTITY 自动赋值）。

## 不需要改动的部分

- Casbin adapter（`internal/app/common/service/casbin.go`）：纯 gdb 抽象，零改动
- 所有业务 logic/dao/model/entity：纯 gdb 抽象，零改动
- 生成的 DAO（`internal/app/system/dao/internal/*`）：字段映射通用
- Docker / K8s 配置：不含数据库连接
- `TRUNCATE` 语句：PG/MySQL 共通语法

## 风险评估

| 风险 | 程度 | 缓解 |
|------|------|------|
| `tinyint`→`smallint` 后 Go 端映射偏差 | 低 | gdb 对 smallint 自动映射 int |
| `datetime`→`timestamp` 时区行为 | 低 | 都不带时区，对齐 `*gtime.Time` |
| 种子 id 与 IDENTITY 冲突 | 已处理 | `GENERATED BY DEFAULT` + `setval` |
| PG 标识符大小写意外 | 低 | 全部 snake_case 小写，无引号 |
